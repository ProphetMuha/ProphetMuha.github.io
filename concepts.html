Key Concepts

Understanding Server Technology

Learning these concepts makes it easier to understand how servers communicate, store information, protect data, and help provide services over computer networks.

Fundamentals

Seven Important Server Concepts

01

Client-Server Model

The client-server model describes the communication between a client and server.The client sends a request, and the server processes that request and returns a response.

Example: A browser requests a webpage from a web server.

02

IP Address

An Internet Protocol address is a numerical identifier that's assigned to a device on a network. It helps information reach the correct device or server.

Example: An IPv4 address may look like 192.168.1.1.

03

Domain Name System

The Domain Name System, or DNS, translates readable domain names into IP addresses that computers can use to find servers.

Example: DNS helps browsers to locate servers that are connected to a website address.

04

Operating Systems

A server operating system manages hardware, software, users, files, network connections, and security settings.

Example: Linux and Windows Server.

05

Virtualization

Virtualization allows one physical computer to operate multiple virtual servers. Each virtual server can run its own operating systems and applications.

Benefit: Organizations can use their physical equipment far more efficiently.

06

Cloud Computing

Cloud computing provides servers, storage, software, and other computing resources through the internet. Customers can increase or decrease resources as much as needed.

Examples: AWS, Microsoft Azure, and Google Cloud.

07

Server Security

Server security includes the tool and procedures used to protect servers from any unauthorized access, malware, or data loss.

Example: Firewalls, updates, strong passwords, encryption, and backups.

Process

How a Client and Server Communicate

  1. 1

    The user enters a website address

    The user enters a domain name into a web browser.

  2. 2

    DNS locates the server

    DNS helps translate the domain name into the server's IP address.

  3. 3

    The browser sends back a request

    The client requests a webpage or another resource from the server.

  4. 4

    The server responds

    The server processes the request and sends the requested files back to the browser.
