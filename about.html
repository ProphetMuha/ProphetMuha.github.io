Project Purpose

About ServerHUB

ServerHub was created as a class project meant to educate others about computer servers and how they fit into different server technologies.

The website explains server history, major types of servers, important technical concepts, and the role that servers play into everyday digital services. Each page is organized into a collection of information about servers, their history, concept, etc.

Project Objectives

  • Explain server technology in an understandable language
  • Describe how server technology has developed over time
  • Compare major types of computer servers
  • Define important server and network concepts
  • Provide reliable resources
  • Demonstrate proper use of HTML and CSS
